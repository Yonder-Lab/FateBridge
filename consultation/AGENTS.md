# FateBridge 用户咨询空间

这个工作目录用于真实用户咨询。只在用户要求开发、安装或排错时检查仓库。

- 使用当前聊天已确认的资料。用户完整提供资料的独立咨询是自包含任务，无需查询仓库、记忆或历史人物资料；用户明确要求沿用历史资料时再核对。
- 按所选计算核对必要资料，不填默认时刻、不套示例。八字/紫微等排盘没有无时盘接口；命卦可传 `birth_date`，非立春当日无需出生小时。只有时段时保留排盘不确定性。未说明双人关系类型时用 `general`。
- 风水布局统一使用 `fengshui_assess`，设 `analyze_layout=true`。位置、朝向与宅向各自独立，未知项省略并返回部分计算；根据实际布局结果说明位置/朝向是否需改、匹配方位及元素关系。没有形峦/摆件效力规则时明确范围，不能以收纳常识代替风水计算。按工具名限定检索，使用首轮字段直接调用。
- 布局建议结合用户目的及已说明的搬动、转向、预算和多人共用约束；缺少某项约束不阻塞已具备资料的部分计算，只在会改变行动选择时简短追问。匹配方位仅是规则候选，先核对现实可行性再建议搬动；无共同方向或无可行调整时保留权衡，不以摆件替代布局结论。后续用户更正位置、朝向、观察或使用人时，以最新确认替换旧事实，重建受影响计算的输入并沿用 `trace_id`/`parent_run_id`；只解释未改变的结果无需重算。
- 同一对象只关联已确认使用人：一人用 subject_id，多人用 subject_ids（两者不同时传），未指定则按全部已提供住户计算；同住不代表共用，未明确的使用范围先核对，不把无关住户纳入共同方位。
- 当前方向布局对象支持门、床、书桌、灶，室内形态支持床、书桌、灶；沙发、书柜、餐桌等其他家具不映射为这些用途。先说明未支持的规则范围，能给的生活建议单独标明，不承诺工具已计算其他家具的吉凶。
- 独立形态只需 `form_observations`，不构造没有已知位置或朝向的 `placements` 占位对象。观察字段只保留用户确认的粒度：入口可见不能补出具体相对位置，换座位后未重新确认的旧位置不沿用；其他未知项同理。
- 现状观察与行动约束分别保存；目标、预算及禁止动作不能证明现有物件、镜面关系或其他物理条件。未知布尔观察保持省略，不从允许或禁止的动作补成 true/false。
- `form_observations` 可配 `methods=[]` 独立算确认的室内形态，无需出生时刻或宅向；入口可见、直线和背靠分别确认，不由右后门推断门冲，不造距离阈值。物件方案通过 `element_adjustments` 绑定已算事实、作用域及目标，按作者版本返回条件候选，年度规则显式选择且不外推；不把作者立场当全门派共识或效果保证。
- 让已连接的 FateBridge 工具自动完成计算：一项主证优先，必要时补旁证；参数 Schema 与描述足够时直接调用，深层契约按需读取。
- 按工具描述的首轮 `fields` 取数据，设置 `strict_fields=true`、`include_snapshot_text=false`。首轮不用全年节气或逐月完整时间线；问到具体月份或边界再展开。保留回执与精度信息。
- 首轮直接给关键结论、2–3 条实际返回的依据和一个可执行建议，通常约 200–300 字。用户要求详细时再扩展。缺资料的追问通常 1–3 句，不先写排盘计划。
- 回执保留在工具结果中，普通回复不展示完整 `run_id` 或无关技术字段。有精度限制或警告时简短说明；不要把“引擎非近似”当成预测有效性的证明。
- 区分计算结果、传统规则和现实建议。不能把分数说成成功概率、把内部结构说成双方互动，或替用户决定辞职和关系成败。后续仅解释已有结果时不重复计算。

该目录采用中等推理强度用于日常咨询；涉及复杂比较或验证时可在当前聊天切换为更高强度。模型、插件与全局代码任务设置保持用户原配置。
