# FateBridge vs horosa-skill 功能对比

## 概述

| 维度 | FateBridge | horosa-skill |
|------|-----------|-------------|
| 工具总数 | ~60 个 | 72 个 |
| 语言 | Python (100%) | Python 89% + JS 7% + Shell 1.4% + Java 1.2% |
| 许可证 | 待确认 (README 未明确) | AGPL-3.0 |
| 接口 | REST + FastMCP + CLI | MCP + JSON-first CLI |
| 离线能力 | 核心占星近似离线；推运依赖 kerykeion/Swiss Ephemeris | 完全离线（runtime 从 GitHub Releases 安装） |
| 架构模式 | 中央 ToolSpec 目录自动注册 REST/MCP/CLI | 类似：中央工具注册 + MCP/CLI |

## 总结

### horosa 相对 FateBridge 的核心优势
1. **推运技法广度**：24 vs 11，多出 13 个高级西占推运技法
2. **神数体系**：全 14 路神数，FateBridge 完全没有
3. **古典占星深度**：47 套岁差、古典详断、围攻、Almuten 等
4. **Agent 参数确认**：61 个工具强制追问缺失参数，防止 AI 乱补
5. **本地记忆系统**：SQLite + JSON artifact 持久化每次分析
6. **离线 runtime**：完整打包，断网可用
7. **卜卦/择日引擎**：西洋 horary + electional 完整判断引擎
8. **数算体系**：邵子参评数、河洛理数、调波盘

### FateBridge 相对 horosa 的核心优势
1. **八字多维分析**：9 个专项维度（婚姻/事业/财运/健康/子女/学业/性格/六亲/正缘桃花），horosa 只有基础命盘
2. **REST API**：完整 FastAPI 接口 + Swagger/ReDoc + API Key 鉴权
3. **Skills 场景层**：8 个 Onda 场景技能 + 共享解读 voice
4. **字段投影**：token 预算控制，按需裁剪响应
5. **紫微运限**：独立的运限工具（大限/小限/流年/流月/流日/流时 + 动态四化）
6. **宿曜合盘**：三九の秘法，二十七宿相性分析
7. **梅花易数**：独立的梅花易数时卦工具
8. **六壬流年**：独立的六壬流年分析工具
