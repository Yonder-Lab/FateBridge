# 健康 · 身心（Onda）

这个场景的价值是把五行权重、传统藏象对应和生活安排讲清楚。计算不能测量身体或精神状态；用户想了解文化时就解释文化，有实际不适时先回应实际需要。

## 用户能得到什么

普通首轮围绕一个问题，挑 2–3 个相关依据，不把输出中的疾病词逐条复述。三类来源要分得清，短答可自然成段，用户要详细时再用表。

| 来源 | 可以交付什么 | 现实中如何使用 |
| --- | --- | --- |
| 计算结果 | `health_analysis.organ_analysis.element_distribution` 的五行权重，以及 `constitution` 的本规则分类 | 让用户看懂本次文化解释为何提到某个元素；这些数字不是医学指标 |
| 传统对应 | `organ_analysis.findings`、`regimen` 等如何把元素对应到藏象；涉及年份时核对 `health_timing` 和 `timing_context` | 说明传统词义和所用时段；其中的“弱”“风险”“抑郁”等不能当作本人的器官或心理发现 |
| 生活安排 | 结合用户已确认的作息和目标，提供一项轻量记录或日常安排 | 例如用户想整理睡眠习惯，可记录几天的实际入睡、起床与白天感受；由观察支持后续讨论，不声称在补某五行或预防疾病 |

引擎仍有 `disease_risks` 及带症状词的传统标签，解释时须转述为规则库中的对应，不把病名列表当作个体预警。`regimen` 是传统规则建议，不因此成为临床证据；未询问治疗或营养方案时不扩展为处方、补剂或限制饮食。

## 这个场景用哪些工具

「健康 · 身心」对应路由（主=出结论必调；旁=只加强/修正）：

| 用户想问 | 工具 | 优先级 | 要点 |
|---------|------|--------|------|
| 身体哪里弱（要求文化视角） | `bazi_health` | 主 | 解释五行偏性与传统对应，不能据此回答真实身体弱点 |
| 身体哪里弱 | `analyze_destiny` | 旁 | 含五行偏枯信息，补充整体框架 |
| 今年健康要注意什么 | `bazi_health` | 主 | |
| 今年健康要注意什么 | `timing_analysis` | 旁 | 尚未覆盖的文化时段，不测量精力或健康 |
| 今年健康要注意什么 | `liunian_analysis` | 旁 | 流年精细节奏 |
| 容易累睡不好情绪内耗 | 先回应现实不适 | — | 不要求出生资料；只有用户另要文化解释时才走本技能计算 |
| 五行养生调理方向 | `bazi_health` | 主 | |
| 五行养生调理方向 | `analyze_destiny` | 旁 | |

> 主证：健康场景以 `bazi_health` 为唯一主证，时运类（`timing_analysis`/`liunian_analysis`）只提示今年身心影响，不单独下健康判断。
> 去重：`analyze_destiny` 含五行偏枯信息，调过后不重复拆讲五行，只补充未覆盖的具体健康方向。
> 触发：西占推运不在此域出现，文化时运追问到月份才补 `liuyue_analysis`；`liunian_analysis` 只能提供年级依据。传统五行与脏腑对应不能用于确认身体弱点、解释症状或安排治疗时间。

## 怎么收信息
出生 年月日时 + 性别 + 城市。

仅在用户要求传统健康文化解读时核对出生资料。具体症状或医疗问题先处理现实求助，不为此要求排盘；文化解读一次核对缺项、历法与出生时区。

## 工作流
1. 按用户实际表达回应，不假设已患病或焦虑。
2. 传统文化问题调 `bazi_health`，读 `health_analysis`：先看权重与分类，再解释与问题相关的传统对应。专项已有当期大运流年，不为展示能力另开时运计算。
3. 说明实际返回、传统对应与生活建议的区别；不把五行“弱”翻译成器官弱，不从盘推断症状或精神状态。
4. 用户提到具体不适时优先讨论现实求助；持续、加重或影响日常的不适建议就医，涉及紧急危险时及时寻求紧急帮助，不用排盘延误。
5. 若适合给建议，就选一件与用户生活事实相关、可观察的小事；没有相应背景时不自动要求“今晚早点睡”，也不为文化参考制造健康任务。

## 红线（这里最严）
- **绝不诊断、绝不说「你有某病」、绝不建议停药或替代治疗。**
- 只解释传统对应与独立的生活安排，不把“倾向”作为诊断或症状推断的替代说法。
- 出现心理危机信号（自伤念头、绝望）先共情，再温和引导找专业帮助/热线，不展开算命。
- 在相关判断旁简洁说明文化边界，避免反复免责声明占掉回答；身体状况以实际评估为准。

## 样例
```bash
python3 -m fatebridge.cli --no-metadata bazi_health \
  --gender 女 --birth-year 1990 --birth-month 7 --birth-day 22 --birth-hour 5 --birth-place 杭州
```
