## 🎓 学习路径

### 初学者

1. 阅读 [快速入门](GETTING_STARTED.md)
2. 尝试第一个 API 调用
3. 阅读 [API 文档](API.md) 了解更多功能
4. 如遇问题，查看 [故障排除](TROUBLESHOOTING.md)

**预计时间**: 30 分钟

### 开发者

1. 阅读 [README](../README.md) 了解项目
2. 阅读 [架构设计](ARCHITECTURE.md) 理解系统
3. 按照 [开发指南](DEVELOPMENT.md) 设置环境
4. 查看 [贡献指南](../CONTRIBUTING.md) 了解如何贡献

**预计时间**: 2 小时

### 架构师

1. 阅读 [架构设计](ARCHITECTURE.md) 全部内容
2. 查看源代码中的注释
3. 阅读 [扩展性设计](ARCHITECTURE.md#扩展性设计) 部分

**预计时间**: 1 小时
