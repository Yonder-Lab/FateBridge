# 西占分析小时／分钟修复与重算验收

已修复共享请求合同与目标时间构造路径，支持 `analysis_hour`（0–23）和
`analysis_minute`（0–59）。REST 请求体、MCP 参数、CLI 的
`--analysis-hour` / `--analysis-minute` 使用同一合同。

根因是 `WesternTimingRequest` 缺少这两个字段，而
`build_analysis_datetime` 固定复用出生钟时。修复同时覆盖聚合入口和
11 个单项推运工具。显式零值有效；省略其中一项时分别沿用出生小时或分钟，
维持既有日期级调用。分析钟时按 `birth_timezone` 解释，地点时区转换保留同一
UTC 时刻，出生资料不随分析钟时改变。
