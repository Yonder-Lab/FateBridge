## 交叉审核与验证

交叉审核发现并补齐了显式导出的未命名前言、422 OpenAPI 声明，以及新增 MCP 别名处理在最低依赖下的兼容问题。MCP 保留原有参数名称，REST 别名契约保持不变。真实 MCP Client 已覆盖全部 80 个工具的代表请求。

最终本地验证使用 Python 3.13.5、FastMCP 3.4.2、Pydantic 2.13.4、Kerykeion 5.12.9：

```sh
PATH="$PWD/.venv/bin:$PATH" .venv/bin/python -m pytest -q
.venv/bin/mypy src/fatebridge
.venv/bin/black --check src/fatebridge scripts tests
.venv/bin/isort --check-only src/fatebridge scripts tests
git diff --check
```

结果：**906 passed、82 skipped、3 warnings**；mypy 的 104 个源文件通过；black、isort 和差异空白检查全部通过。

另在隔离依赖环境中验证 FastMCP 3.0.0 + Pydantic 2.11.7，相关 26 项全部通过；当前依赖的 MCP、CLI、discovery、metadata 合集 70 项通过。

星历恒星校准测试改为在测试执行期间设置目录并自动恢复，避免收集阶段污染全局状态。既有“完整非法日期自动改月底”的测试改为验证部分日期补齐与完整日期拒绝。

验证边界：本地为 macOS；黄金快照逐字节比较锁定 Linux x86_64/Python 3.12，在本机按仓库规则跳过。该参考环境的 CI 未在本轮触发；未在 Mac 上重写黄金快照。依赖产生的三个原有警告仍存在。上述 13 项在已执行的代码、协议和回归复核范围内未发现遗留问题。
